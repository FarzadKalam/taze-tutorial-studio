# استودیوی آموزش تازه‌سیستم

ابزار مستقل و قابل‌ادامه برای ساخت آموزش از رابط واقعی محصول. عامل Codex موضوع را بررسی و سناریو را می‌نویسد؛ ابزارهای نسخه‌دار ضبط مرورگر، صدا و تدوین را اجرا می‌کنند. به kalam-video-kit وابسته نیست. وضعیت MVP: ضبط fixture و بستهٔ پیش‌نویس محلی؛ انتشار خودکار production هنوز پیاده نشده است.

## شروع برای همکار

Node 22.12 یا بالاتر و دسترسی مجاز به سورس تازه‌سیستم لازم است. این ریپو و Kalamapp را کنار هم checkout کنید، یا `KALAMAPP_ROOT` را روی مسیر checkout محصول بگذارید. وابستگی‌های محصول هم باید برای سیستم‌عامل همان محیط نصب باشند. فایل `.env.example` فقط نام تنظیمات را دارد؛ کلید یا نشست را از همکار دیگری کپی نکنید.

```sh
npm ci
npm run source:setup
npm run setup
npm run preflight
```

`source:setup` ریپوی خصوصی [KalamApp](https://github.com/FarzadKalam/KalamApp) را در مسیر `KALAMAPP_ROOT` دریافت و وابستگی‌هایش را نصب می‌کند. اگر سورس از قبل هست آن را pull، reset یا بازنویسی نمی‌کند. هر همکار باید در GitHub به **هر دو ریپو** دسترسی خواندن داشته باشد؛ دسترسی به استودیو به‌تنهایی دسترسی به محصول نمی‌دهد. در Codex ابری نیز هر دو ریپو باید در همان محیط قابل دریافت باشند. سورس محصول و تنظیمات خصوصی آن داخل این ریپو کپی نشده‌اند.

در Codex با همین ریپو بنویسید:

> از مهارت tutorial-producer استفاده کن. آموزش اتصال بات بله را براساس سورس فعلی تازه‌سیستم بساز. اول محیط اجرای خودت را بررسی کن؛ اگر آماده نبود دلیل و مسیر ادامه را ثبت کن. صدا از سرویس فعلی تازه‌سیستم باشد. پیش‌نویس را برای بازبینی آماده کن.

مهارت در `.agents/skills/tutorial-producer/SKILL.md` است. منطق عامل از نشست Codex استفاده می‌کند و فراخوانی پنهان OpenAI API ندارد. تولید صدا مصرف سرویس انتخاب‌شده را دارد و مستقل از اشتراک عامل است.

## محیط ابری اول، محلی در صورت نیاز

ابزارها در محیطی اجرا می‌شوند که نشست Codex واقعاً به آن دسترسی دارد. در sandbox ابری، مرورگر headless و خروجی همان‌جا هستند. در Codex محلی، محیط جاری همان کامپیوتر است؛ `setup` محیط cloud نمی‌سازد. نیازی به ضبط دسکتاپ یا مرورگر شخصی نیست. در Linux، `npm run setup` در نبود مرورگر Chromium را با Playwright آماده می‌کند؛ نصب وابستگی‌های سیستمی به مجوز محیط نیاز دارد.

`TUTORIAL_ENVIRONMENT_KIND=codex-cloud` فقط برچسب گزارش است، نه راه اتصال به cloud. راه‌اندازی محیط ابری و دسترسی به ریپوی خصوصی باید توسط صاحب محیط فراهم شده باشد. [راهنمای رسمی محیط‌های Codex](https://developers.openai.com/codex/cloud/environments)

## دستورات یک آموزش

```sh
npm run plan -- bale-connection
npm run review -- bale-connection
# متن و سناریو را به صاحب کار نمایش دهید؛ تا تأیید واقعی ادامه ندهید.
# پس از تأیید، approve را با hash نسخه و مرجع پیام واقعی او اجرا کنید.
npm run next -- bale-connection
npm run voice -- bale-connection
npm run capture -- bale-connection
npm run compose -- bale-connection
npm run handoff -- bale-connection
```

بدون تأیید همان نسخهٔ متن، نریشن و سناریو، `voice`، `capture`، `compose` و رندر متوقف می‌شوند. بعد از تأیید، اگر نشست سرویس صدا موجود نباشد تولید صدا متوقف می‌شود؛ پیش‌نمایش بی‌نریشن با انتخاب صاحب کار ممکن است و برچسب دارد. پس از آماده‌شدن صدا، ضبط مجدد زمان هر گام را از همان صوت واقعی می‌گیرد.

مسیر composition را دستور compose چاپ می‌کند. check، snapshot، preview و render را با wrapper اجرا کنید:

```sh
npm run hf -- check <composition-path> --json
npm run hf -- snapshot <composition-path> --at 2,8,15 --describe false
npm run hf -- preview <composition-path>
npm run hf -- render <composition-path> --output <composition-path>/final.mp4 --concurrency 1
```

## اتصال صدا

انتخاب مالک: سرویس فعلی هوش مصنوعی تازه‌سیستم، action برابر `generate_voice_output`. در محیط دارای نمایشگر، `npm run connect -- https://app.tazesystem.ir` یک مرورگر جدا برای ورود به حساب تولیدکننده باز می‌کند؛ نشست کوتاه‌مدت فقط در `.local` ذخیره می‌شود. هر فرد با حساب خودش وارد شود؛ اطلاعات عمومی اتصال از ورود رسمی شناسایی می‌شود و کپی کلید خصوصی یا env شخص دیگر لازم نیست. OTP را در همان صفحهٔ رسمی وارد کنید. پس از انقضا دوباره وارد شوید. این دستور نیازمند تعامل صاحب حساب است و در cloud بدون نمایشگر اجرا نمی‌شود؛ مسیر OTP جدا به درخواست مالک اضافه نشده است.

برای نمونهٔ بله فعلاً صاحب کار خودش صوت می‌دهد؛ تولید پولی را اجرا نکنید. با `npm run narration -- bale-connection` متن دقیق بدون عنوان و شمارهٔ صحنه در `.local/projects/bale-connection/NARRATION.txt` آماده می‌شود. دریافت یک فایل کامل صوتی هنوز به هم‌ترازی واقعی با صحنه‌ها نیاز دارد؛ مدت‌ها را تخمینی تقسیم نکنید.

در `.env` محلی یا secrets محیط هم می‌توان `TAZE_AI_URL` و نشست `TAZE_AI_ACCESS_TOKEN` متعلق به حساب تولید محتوا را تنظیم کرد؛ `TAZE_AI_ANON_KEY` برای gateway در صورت نیاز. کلید service-role برای این endpoint مناسب نیست. مدل در `voice.model` سناریو انتخاب می‌شود؛ نمونهٔ بله Gemini 3.8 Flash-Lite TTS را درخواست می‌کند. `TAZE_VOICE_MODEL` اولویت بالاتر دارد. اگر هیچ‌کدام تعیین نشده باشند، مدل تنظیم‌شدهٔ حساب انتخاب می‌شود. فقط مدلِ برگشتیِ پاسخ سرویس را اجرای واقعی همان مدل حساب کنید.

نام، لوگوی F01، پالت و فونت‌ها مستقیماً از `PublicSite` checkout جاری خوانده و همراه اثرانگشت فایل‌ها در `brand-snapshot.json` هر تدوین ثبت می‌شوند. رنگ manifest موبایل مرجع پالت تدوین نیست. تغییر تم یا لوگوی محصول، برداشت قبلی را برای تولید تازه منقضی می‌کند.

## خروجی و حدود واقعی

در `.local/projects/<id>`: وضعیت مراحل، برداشت‌های جداگانه، صدا، composition، زیرنویس و `cms-draft.json`. فایل CMS هنوز فایل ویدیو ندارد و بدون آپلود رسانه و تکمیل بازبینی قابل انتشار نیست. شبکهٔ fixture به تولید متصل نمی‌شود و پاسخ‌های شبیه‌سازی‌شدهٔ آن با نشان آموزشی در تصویر مشخص‌اند.

نمونهٔ بله اکنون مسیر ساخت بات و گرفتن توکن، ارسال پیام و بررسی دریافت را داخل قاب گوشی هم توضیح می‌دهد. بازسازی از مدل مستقل `external-apps` می‌آید و نشان آموزشی دارد. `npm run test:phone` پنج حالت آن را در مرورگر بررسی می‌کند. مدل صدای این سناریو Gemini 3.8 Flash-Lite TTS و صدای پیشنهادی Charon است؛ تا تأیید نسخهٔ تازه تولید نمی‌شود.

سلیقهٔ تدوین از توضیحات مالک در video-kit استخراج و در `editing/product-tutorial.json` ثبت شده است؛ برای اجرای پروژه به آن کیت نیاز نیست. زوم به هدف واقعی تعامل و بازگشت به نمای کامل، رد کوتاه ماوس و حلقهٔ کلیک جزو بررسی هستند. راهنمای بازسازی: `docs/EXTERNAL_APPS_FA.md`.

سناریوی بعدی روبیکا و سپس اتصال مخاطب به گروه با کد فعال‌سازی است. مستند معماری: `docs/ARCHITECTURE_FA.md`.

## منابع بررسی‌شده

- [Playwright](https://github.com/microsoft/playwright): اجرای مرورگر و CDP؛ وابستگی نصب‌شده.
- [Demo-Forge](https://github.com/DixitRam/Demo-Forge): مرجع فنی ضبط فریم‌های screencast و ثبت تعامل؛ کد آن در این MVP کپی نشده و اجرای آن وابستگی نیست.
- [HyperFrames](https://github.com/heygen-com/hyperframes): موتور مستقل رندر؛ وابستگی نسخه‌دار.
- [Ultrademo](https://github.com/andrewluxem/ultrademo): مرجع تفکیک سناریو، صدای هر صحنه و بازتولید.

مجوز فونت و دارایی محصول به مالک آن تعلق دارد؛ سورس محصول و فونت‌ها در این ریپو بازنشر نمی‌شوند. ریپوی استودیو خصوصی است: https://github.com/FarzadKalam/taze-tutorial-studio . دسترسی همکاران به استودیو و KalamApp را جدا تنظیم کنید.
